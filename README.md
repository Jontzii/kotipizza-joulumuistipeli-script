# Kotipizza joulumuistipeli script

This repository contains a script that automates playing the Kotipizza Christmas memory game. The script uses Puppeteer to interact with the game website, allowing users to play multiple rounds automatically.

## Disclaimer

This script is intended for educational purposes only and using it may break terms of service of the game. The author is not responsible for any misuse of this script.

## How to use

1. `npm ci` to install dependencies.
2. `KOTIPIZZA_EMAIL=your-email@example.com ROUNDS_TO_PLAY=10 node index.js` to run the script.
